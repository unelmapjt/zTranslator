description=[h2]■ 主な特徴[/h2]
description=[list]
description=[*] [b]完全非破壊（Zero-Destruction）:[/b] 元MODのファイルを1文字も改変せず、独立したパッチMOD（require=<MOD_ID>）を自動生成。
description=[*] [b]差分更新（Incremental Update）:[/b] MODがアップデートされても、過去の翻訳を100%自動継承し、新規追加テキストのみを抽出。
description=[*] [b]全MOD形式ハイブリッド対応:[/b] 公式JSON、手記・ストーリー（printMedia txt）、ソース直書き（ハードコードUI）を全自動判別。
description=[*] [b]UI文字幅セーフ（はみ出し防止）:[/b] 英語固定幅ボタンからの突き抜けを防ぐ「幅注意」自動検知＆文字幅リアルタイムアシスト。
description=[*] [b]多彩なAIエンジン:[/b] 内蔵スマート辞書（完全オフライン・即動作）、OllamaローカルLLM（未起動時の自動起動・保有モデル一覧表示・中断停止ボタン完備）、クラウドAI（Gemini無料枠 / Groq / DeepSeek）。
description=[*] [b]ゲーム内トグル対応:[/b] ModOptions設定からゲーム再起動不要で即座に日本語と英語を切り替え可能。
description=[/list]

description=[h2][English Description][/h2]
description=[h1]zTranzlator - Build 42 Mod Translation Suite[/h1]
description=A zero-destruction, incremental AI translation tool suite for Project Zomboid (Build 42), inspired by Skyrim's xTranslator.
description=Features a clean modern GUI supporting 35,000 vanilla dictionary terms, Local LLMs (Ollama with auto-launch, model list, and abort support), and Cloud AI (Google Gemini, Groq, DeepSeek, OpenAI).
description=
description=[h2]■ Motivation & Behind the Mod[/h2]
description=Project Zomboid has been out for many years, yet it remains deeply loved by a massive community of players, creators, and streamers worldwide.
description=While the modding scene is thriving, the language barrier can still be a formidable obstacle for players wanting to experience new creations.
description=I built this tool with the simple hope that anyone can easily enjoy un-translated mods in their own language.
description=
description=It is still in alpha and far from perfect, but please feel free to try it out!
description=My sincere apologies if it doesn't work perfectly on every single mod.
description=[i]May Project Zomboid continue to be a game that brings endless joy to everyone for years to come![/i]
description=
description=[h2]■ Key Features[/h2]
description=[list]
description=[*] [b]Zero-Destruction:[/b] Generates standalone companion patches (require=<MOD_ID>) without modifying original mod files.
description=[*] [b]Incremental Updates:[/b] Seamlessly inherits past translations when base mods are updated, highlighting only newly added strings.
description=[*] [b]Universal Format Support:[/b] Automatic handling of Translate JSON, printMedia text, and hardcoded Lua UI hooks.
description=[*] [b]UI Overflow Safe:[/b] Real-time character width ratio calculation preventing text truncation.
description=[*] [b]Multi-Engine Architecture:[/b] Smart Offline Dict, Local Ollama, and Cloud AI API.
description=[*] [b]In-Game Toggle:[/b] Switch between Japanese and English on the fly via ModOptions.
description=[/list]
