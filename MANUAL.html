⚡ 3ステップ最短ガイド (日本語)

「難しい設定は後回しにして、とにかく今すぐMODを日本語で遊びたい！」という方のためのクイックマニュアルです。

💡 完全非破壊パッチ方式: 元MODのファイルを1文字も書き換えません。連動する独立パッチMOD（require 形式）を作成するため、安心していつでも試せます。

📋 事前準備チェック（初回のみ）

1. Python 3.10以上: インストール時に一番下の Add python.exe to PATH に必ずチェックを入れておいてください（忘れるとbatが起動しません）。
2. Ollama (推奨): ollama.com からインストールしておくと、アプリ起動後に1クリックで推奨AIモデル（gemma4:e4b）をダウンロードして完全無料・無制限のAI翻訳ができます。

1
アプリを起動する

MODフォルダ内の run_zTranzlator.bat をダブルクリックします。
必要なライブラリが自動チェックされ、ダーク調のモダンUIが起動します。

2
左リストからMODを選び、翻訳を実行する

1. 左側のツリーから翻訳したいMODをクリックします（サブスクライブ済みのMODが自動検出されます）。
2. 最初は「公式一致（バニラ共通）」テキストが自動で照合されます。
3. MOD独自の英語文章もすべて翻訳したい場合は、右上の ［⚙️ 翻訳設定］ を開き、「🦙 Ollama (ローカルLLM)」 または 「Gemini (API)」 を選択して、画面右下の ［一括AI翻訳を実行］ を押します。

3
ゲームへ適用してプレイする

1. 翻訳が終わったら、画面下の ［ローカルMOD適用 (Zomboid/mods)］ をクリックします。
2. C:\Users\<ユーザー名>\Zomboid\mods\<MOD名>_JA に自動インストールされます。
3. Project Zomboid を起動し、タイトル画面の 「MOD」 メニューで 「<MOD名>_JA」 にチェックを入れて有効化するだけで完了です！

🎮 ゲーム内オプションで日/英を即座に切り替え可能

ゲーム内の「オプション」➡「Mod設定 (Mod Options)」を開くと、MODごとに日本語と英語を切り替えるトグルスイッチが用意されています。ゲームを再起動せずに言語を戻すことも可能です。

※ より詳細な設定、元MODフォルダ構造の継承仕様、Ollamaモデルの選び方、Steamワークショップ配布方法などは、上部の ［📚 詳細版］ タブをご覧ください。

⚡ 3-Step Quick Start Guide (English)

A fast track guide to translate and enjoy your Project Zomboid Build 42 mods immediately without complicated setup.

💡 Zero-Destruction Architecture: Never modifies original mod files. Creates an independent companion patch (require dependency). Safe to test and remove anytime.

📋 Prerequisites Checklist (First-time only)

1. Python 3.10+: Ensure Add python.exe to PATH was checked during installation (required for the batch launcher).
2. Ollama (Recommended): Install from ollama.com to enable 100% free, offline, unlimited AI translation using recommended models like gemma4:e4b.

1
Launch the Application

Double-click run_zTranzlator.bat inside the tool folder.
Required dependencies will be verified and the modern desktop interface will launch.

2
Select Mod & Run Translation

1. Click any installed mod on the left mod list.
2. Vanilla-matched strings are matched instantly via the built-in dictionary.
3. For custom mod strings, open ［⚙️ Settings］ at the top right, choose "🦙 Ollama (Local LLM)" or "Gemini API", then click ［Run Batch AI Translation］.

3
Apply to Game & Play

1. Once translated, click ［Apply Mod to Local (Zomboid/mods)］ at the bottom.
2. The patch mod is automatically created in Zomboid/mods/<ModID>_JA.
3. Start Project Zomboid, navigate to the "MODS" menu, and enable your new patch mod!

🎮 In-Game Language Toggle (ModOptions)

Under game Options ➡ Mod Options, you will find quick toggle checkboxes to switch between the translated patch and original English without restarting the game.

※ For technical details, directory structure inheritance, Ollama models, and Workshop distribution, click the ［📚 Detailed］ tab above.

1. 環境構築ガイド (Python ＆ Ollama の導入手順)

Step 1: Python 3.10+ のインストール

zTranzlator は Python で動作するオープンソースツールです。PCにまだ Python がインストールされていない場合は、以下の手順で導入してください：

  1. Python 公式ダウンロードページ (python.org) から最新の Windows インストーラーをダウンロードします。
  2. インストーラーをダブルクリックして起動します。
  3. ⚠️ 超重要（ここを忘れると起動しません）:
    インストーラー最下部にある 「Add python.exe to PATH」（PATHを通す）に必ずチェック を入れてください。
    ※チェックを入れずに進めると、batファイル起動時に「'python' はコマンドとして認識されていません」と表示されてしまいます。
  4. ［Install Now］ をクリックして完了を待ちます。
  5. ライブラリの自動セットアップ: zTranzlator フォルダ内の run_zTranzlator.bat をダブルクリックするだけで、初回起動時に必要なモジュール（GUIライブラリ、通信モジュール等）が全自動で安全にダウンロード＆インストールされます。

Step 2: Ollama の導入 (ローカルLLM実行基盤)

ローカルAIによる完全無料・無制限・通信不要の翻訳を行うエンジンです：

  1. Ollama 公式サイト (ollama.com) から Windows 版をダウンロードしてインストールします。
  2. インストール後、Windows のタスクバー通知領域（右下のインジケーター）に アルパカ（ラマ）のアイコン が常駐していればセットアップ完了です（PC起動時に自動でバックグラウンド待機します）。

Step 3: AI翻訳モデルのダウンロード (2通りの方法)

翻訳を実行するには、Ollama 内に翻訳用のAIモデル（重みデータ）を取得しておく必要があります：

【方法A: zTranzlator の画面から1クリック (推奨・一番簡単)】

zTranzlator を起動した際に出る「クイックスタート」画面（または上部「設定」➡「モデルのダウンロード」）で、推奨モデル（gemma4:e4b）を入力してダウンロードボタンを押すだけで、自動取得されます。

【方法B: コマンドプロンプト / PowerShell から直接取得】

Windowsのスタートメニューから「PowerShell」または「コマンドプロンプト」を開き、以下のコマンドを入力して Enter を押します：

ollama run gemma4:e4b

※約6.1GBのダウンロードが行われ、完了すると対話プロンプトが出ます。確認後は /bye と打つかウィンドウを閉じて構いません。
※超低スペック環境でお試しする場合は ollama run qwen2.5:3b も利用可能です。

Step 4: Google Gemini API の設定 (任意・クラウドAIを利用する場合)

ローカルGPUを搭載していないノートPCや、より高速な翻訳を行いたい場合は Google Gemini（クラウドAPI）も利用できます：

  • Google AI Studio (aistudio.google.com) にGoogleアカウントでログインし、［Get API key］ から無料のAPIキーを取得します。
  • zTranzlator のエンジン選択で「Google Gemini」を選び、キーを入力して「保存」するだけで即座にクラウド翻訳が有効になります。

2. 基本理念とアーキテクチャ

Skyrim「xTranslator」に着想を得た完全非破壊・差分更新設計

従来のゲーム翻訳では、元MODのファイルを直接上書き改造して日本語化することが一般的でした。しかしこの方法では、元MODがアップデートされた瞬間に翻訳が消滅したり、コードの改変によってゲームがクラッシュするリスクがありました。

zTranzlator は、Project Zomboid Build 42 の公式MOD依存機構（require=<MOD_ID>）を徹底活用し、元MODのファイルには1文字も触れずに連動パッチを出力します。ゲームは元MODを先に読み込み、その直後にパッチMODをオーバーレイとして適用します。

3. 元MODのフォルダ構造の継承と反映の仕組み

「元のフォルダ構造はちゃんと継承されるのか？」への回答

はい、元MODの階層構造を100%忠実に継承し、Project Zomboid Build 42 の読み込み仕様に合わせて最適出力されます。

MOD内のテキストはデータ形式によって保存場所が異なりますが、zTranzlator は以下の3大アーキテクチャを全自動判別して適切なディレクトリに配置します：

🔄 モデルの更新 ＆ Ollama 本体のアップデート方法

Ollama やダウンロード済みモデルは、以下の簡単な手順で最新状態に保守できます：

  • Ollama 本体の更新: 新バージョンが公開されると、タスクバー右下の通知領域（ラマアイコン）にポップアップ通知が出ます。クリックして再起動するだけで自動更新されます（または公式サイトから最新版インストーラーを上書き実行しても、ダウンロード済みモデルや設定はすべて消えずに保持されます）。
  • AIモデルの最新版への更新: ターミナルで ollama pull <モデル名>（例: ollama pull gemma4:e4b）を実行すると、更新がある場合のみ差分がダウンロードされて最新版に上書き更新されます（zTranzlator の「設定」➡「直接DL」を押しても同様に最新化されます）。
  • 使わなくなったモデルの削除（空き容量確保）: コマンドプロンプト等で ollama rm <モデル名>（例: ollama rm qwen3.5:9b）と打つだけで、数GB〜十数GBのストレージ容量を即座に解放できます。

9. よくある質問 (FAQ)

Q. ゲーム内で翻訳が反映されない場合のチェックリスト

A. 以下の3点をご確認ください：
1. ゲームの「MOD」画面で、元MODとパッチMOD（_JA）の両方が有効になっているか。
2. ロード順で、パッチMODが元MODよりも後（下）に配置されているか。
3. ゲーム内言語が「日本語」に設定されているか。

Q. ボタン枠から日本語がはみ出してしまう場合は？

A. MODのボタン幅自体がコード内で固定値（100px等）で指定されている場合、非破壊パッチではボタン自体の物理幅を広げることはできません。該当セルをダブルクリックし、より文字数の短い漢字や略称（例: 「エイム感度」➡「感度」）に短縮して保存してください。

📚 Full Technical Manual (English)

A comprehensive architectural and user guide covering non-destructive patching, folder structure inheritance, Ollama models, telemetry monitoring, and Workshop publishing.

1. Environment Setup Guide (Python & Ollama Installation)

Step 1: Install Python 3.10+

zTranzlator is an open-source Python desktop application. If you don't have Python installed on your PC, follow these steps:

  1. Visit the Official Python Downloads Page (python.org) and download the latest Windows installer.
  2. Run the downloaded installer.
  3. ⚠️ Crucial Requirement (Do not miss this):
    On the first installer screen, make sure to check "Add python.exe to PATH" at the bottom before clicking Install Now.
    ※ If missed, Windows will report "'python' is not recognized as an internal or external command" when running the .bat launcher.
  4. Click ［Install Now］ and wait for completion.
  5. Automatic Dependencies Setup: Simply double-click run_zTranzlator.bat inside the zTranzlator folder. On the first launch, it will automatically and securely download required dependencies (CustomTkinter GUI, requests, psutil, etc.). No manual terminal commands required.

Step 2: Install Ollama (Local LLM Runtime Engine)

Ollama provides a local inference server for 100% free, private, offline AI translation:

  1. Download and install Ollama for Windows from the Official Ollama Website (ollama.com).
  2. Once installed, check your Windows system tray (bottom-right icons near the clock) for the Llama / Alpaca icon. If it's running, Ollama's local inference service (localhost:11434) is ready.

Step 3: Pulling AI Translation Models (2 Methods)

To run translations, you need to download model weights into Ollama:

【Method A: 1-Click via zTranzlator UI (Recommended)】

When zTranzlator launches, the QuickStart modal (or Settings ➡ "Download Model") allows you to enter the recommended model (gemma4:e4b) and click download to fetch it automatically in the background.

【Method B: Directly via Command Prompt / PowerShell】

Open Windows PowerShell or Command Prompt, and run the following command:

ollama run gemma4:e4b

※ The initial pull takes a few minutes (~6.1GB). Type /bye or close the window once done.

Step 4: Google Gemini API Setup (Optional - Cloud AI)

For users without a dedicated GPU or those desiring ultra-fast cloud translation:

  • Log into Google AI Studio (aistudio.google.com) with your Google account and click ［Get API key］ to generate a free API key.
  • In zTranzlator, select "Google Gemini" as your translation engine, paste your API key, and click Save.

2. Concept & Architecture

Inspired by Skyrim's "xTranslator": True Zero-Destruction Patching

Traditional mod translations often overwritten original mod files directly. While simple, this broke whenever the original mod updated on Steam, destroying your translations and potentially crashing your game.

zTranzlator utilizes Project Zomboid Build 42's official dependency mechanism (require=<MOD_ID>) to output a 100% independent companion patch. The game loads the original mod first, followed by your translation patch overlay.

🔄 Updating Models & Ollama Application

You can effortlessly maintain Ollama and its downloaded model weights:

  • Updating Ollama: When a new release is available, click the update notification in your Windows system tray, or download the latest installer from ollama.com. Overwriting will never delete your existing downloaded models.
  • Updating AI Models: Run ollama pull <model_name> (e.g. ollama pull gemma4:e4b) in PowerShell. Ollama checks the registry and downloads only differential layers if updated (or enter the name in zTranzlator Settings ➡ Direct DL).
  • Removing Unused Models: Free up disk space anytime using ollama rm <model_name> (e.g. ollama rm qwen3.5:9b).
